# ServiceCard

Κάρτα υπηρεσίας: φωτογραφία με γωνίες 10px, τίτλος και μία-δύο γραμμές κειμένου· σε πλέγμα τριών στηλών.

Πλάτος 345px, κενό `space-30`. Φωτογραφία `radius-md` (η πηγή: 238px τετράγωνη μέσα στην κάρτα). Τίτλος `card-title` (24px/600, `ink`), κείμενο `body` (`text`). Σκούρα παραλλαγή (`fb-card-dark`): φόντο `surface-slate`, τίτλος `on-dark`, κείμενο `on-dark-muted`· για την υπηρεσία που θέλουμε να ξεχωρίσει. Ο χρήστης δίνει τις φωτογραφίες· καλύτερα πραγματικές δουλειές του συνεργείου.
