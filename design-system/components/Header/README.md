# Header

Διάφανο header πάνω στη φωτογραφία του hero: μενού αριστερά, λογότυπο στο κέντρο, κύκλοι social δεξιά.

Σύνδεσμοι: στυλ `nav` (16px/600) σε `on-photo`, padding 14.4px. Η τρέχουσα σελίδα υπογραμμίζεται. Social: κύκλοι `social-icon` (43px), `radius-full`, φόντο `brand`. Η πηγή βάζει λευκό εικονίδιο πάνω στο κίτρινο (1.4:1, αποτυγχάνει)· κρατήθηκε όπως είναι, αλλά για το site του θείου προτίμησε `on-brand` (μαύρο). Το λογότυπο εδώ είναι placeholder κειμένου μέχρι να έχουμε το δικό του.
