# Button

Τρία κουμπιά: κίτρινο κύριο, λευκό outline πάνω σε φωτογραφία και μαύρο δευτερεύον.

- **Κύριο** (`fb-btn fb-btn-primary`): φόντο `brand`, κείμενο `on-brand`, ύψος `button-h` (52px), padding `button-x`, γωνία `radius-md`, στυλ `button`. Hover: `brand-hover`. Ένα ανά οθόνη, για την κίνηση που θέλουμε: «Δωρεάν εκτίμηση».
- **Outline** (`fb-btn-outline`): διάφανο, περίγραμμα 2px `on-photo`. Μόνο πάνω σε φωτογραφία με `overlay`, δίπλα στο κύριο.
- **Μαύρο** (`fb-btn-dark`): φόντο `button-dark`, 17px/700, padding `space-15`, γωνία `radius-sm`. Σε λευκές ενότητες, π.χ. «Δείτε τις υπηρεσίες».

Κείμενο με ρήμα μπροστά, πεζά με κεφαλαίο το πρώτο γράμμα. Το focus ring (2px `brand`) προστέθηκε εδώ· η πηγή δεν είχε ορατό.
