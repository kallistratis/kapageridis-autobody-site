# EmergencySteps

Ενότητα «Τράκαρες;» πάνω σε φωτογραφία: μεγάλος κεφαλαίος τίτλος, μία πρόταση και τρία βήματα που οδηγούν στο κουμπί chat.

Padding `section-top` / `section-bottom`, φωτογραφία με `overlay`. Τίτλος `title-lg` σε `on-photo`, υπότιτλος `h2-photo`, βήματα `lead` με λευκή γραμμή 2.67px από πάνω (όπως στην πηγή). Τα βήματα πρέπει να καταλήγουν σε πραγματική ενέργεια: Viber ή τηλέφωνο.
