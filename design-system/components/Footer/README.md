# Footer

Σκούρο footer τριών στηλών με ωράριο, επικοινωνία και μενού, όλα κεντραρισμένα.

Φόντο `surface-night`, τίτλοι `card-title` σε `on-dark`, κείμενο 17px σε `on-dark-muted`. Κύκλοι social όπως στο Header. Το όνομα, η διεύθυνση και το τηλέφωνο πρέπει να είναι ίδια με το προφίλ Google της επιχείρησης (NAP), γράμμα προς γράμμα.
