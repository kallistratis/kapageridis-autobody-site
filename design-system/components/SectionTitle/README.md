# SectionTitle

Οι δύο τρόποι που ανοίγει μια ενότητα: αριστερά με eyebrow και τεράστιο κεφαλαίο τίτλο, ή κεντραρισμένα με λέξη-υδατογράφημα από πίσω.

- **Αριστερά**: `eyebrow` (14px/600, 1.8px, κεφαλαία, `ink`) και από κάτω `title-xl` (86px/800, -4.8px, κεφαλαία, `ink-black`). Πάνω σε φωτογραφία: `title-lg` (74px) σε `on-photo`.
- **Κέντρο**: λέξη `watermark-xl` (162px/800, κεφαλαία) σε `watermark` πίσω από `heading-xl` (57px/600, `ink-soft`) και περιγραφή `body` σε `text-muted`.

Στα ελληνικά κεφαλαία δεν μπαίνουν τόνοι: γράψε το κείμενο κανονικά και άφησε το `text-transform: uppercase` να το κάνει κεφαλαίο, ή γράψε κεφαλαία χωρίς τόνους.
