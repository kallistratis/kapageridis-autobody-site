# Hero

Η πρώτη οθόνη: φωτογραφία σε όλο το πλάτος με `overlay` 50%, τίτλος κάτω αριστερά και δεξιά μια σύντομη παράγραφος με δύο κουμπιά.

Τίτλος: στυλ `hero` (69px/600, -0.99px), `on-photo`, πλάτος έως 706px. Παράγραφος: `hero-lead`, έως 310px. Κουμπιά: κύριο + outline (δες Button). Ο χρήστης δίνει τη φωτογραφία (κατά προτίμηση πραγματική από το συνεργείο, όχι stock)· χωρίς αυτή το φόντο πέφτει σε `surface-slate`.
