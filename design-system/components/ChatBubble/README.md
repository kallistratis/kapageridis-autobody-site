# ChatBubble

Σταθερό κίτρινο κουμπί κάτω δεξιά σε κάθε σελίδα, με συννεφάκι μηνύματος που καλεί τον πελάτη να στείλει φωτογραφία της ζημιάς.

Κουμπί: κύκλος `radius-full`, φόντο `brand`, εικονίδιο `on-brand`. Μήνυμα: λευκό, `radius-chat`, σκιά `shadow-float` (η μόνη σκιά του συστήματος), 14px/20px, padding 10/25/10/15. Το μέγεθος του κύκλου (56px) είναι εκτίμηση από screenshot· τα υπόλοιπα είναι ακριβή. Για την Ελλάδα το κουμπί ανοίγει Viber (viber://chat?number=…) ή κλήση.
