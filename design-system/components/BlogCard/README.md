# BlogCard

Κάρτα άρθρου για την ενότητα συμβουλών: φωτογραφία, κατηγορία σε κεφαλαία και τίτλος.

Πλάτος 292px. Κατηγορία: `meta` (14px/600, 0.6px, κεφαλαία) σε `text-meta`, που στην πηγή έχει μόνο 3.3:1. Κράτησέ το για κατηγορίες· για ημερομηνίες ή οτιδήποτε πρέπει να διαβαστεί χρησιμοποίησε `text-muted`. Τίτλος: `blog-title` (18px/600, `ink-soft`). Τα άρθρα βοηθούν και στο Google (τοπικό SEO).
